# Horizon-001: Côte d'Ivoire Economy

## Project Overview

Horizon-001 is an economic data analysis project focused on understanding the macroeconomic evolution of Côte d'Ivoire.

The project explores key economic indicators such as GDP growth, inflation, public debt, employment, and major economic sectors in order to identify trends and provide data-driven insights.

## Objectives

The main objectives of this project are:

- Analyze the evolution of Côte d'Ivoire's main economic indicators.
- Identify major economic trends and challenges.
- Visualize economic data through statistical graphs.
- Apply econometric and data analysis techniques to extract meaningful insights.

## Research Questions

This project aims to answer the following questions:

- How has Côte d'Ivoire's economy evolved over recent years?
- What are the main factors influencing economic growth?
- How have inflation and public debt changed over time?
- Which sectors contribute the most to economic development?

## Data Sources

The project will use publicly available economic datasets from:

- World Bank Open Data
- International Monetary Fund (IMF)
- African Development Bank (AfDB)
- National statistical sources of Côte d'Ivoire

## Methodology

The analysis process includes:

1. Data collection
2. Data cleaning and preparation
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Economic interpretation
6. Statistical analysis
